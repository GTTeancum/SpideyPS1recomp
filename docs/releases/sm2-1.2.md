# Spider-Man 2: Enter Electro 1.2 for Windows x64

## Bug fixes since 1.1

- Restored scenery draw order during the opening level's camera sweep, fixing sections of buildings disappearing or drawing at the wrong depth.
- Corrected costume selection so highlighting a mod character no longer plays a stock character's voice-over.
- Corrected shadow placement on floors and slopes using the collision plane beneath Spider-Man.
- Fixed the window shrinking when entering widescreen gameplay from a maximized menu. Restored the Windows taskbar icon and corrected spacing in the pause-menu quit prompt.
- Fixed small translucent effects disappearing when their projected coordinates crossed the GPU coordinate boundary.
- Corrected elongated feet and neck and back posture on converted suits while preserving Spider-Ham proportions. Repaired mask seams and face alignment on affected suits, including Earth-62412, Spidey New Design, and UK.

## Costumes and controls

Includes 85 external suits from the reviewed roster. SP//DR returns as **SP-DR** in the costume menu. The right stick rotates the gameplay camera and costume viewer. The main menu includes Exit Game.

## Installation

Extract the ZIP to a new writable folder and launch `SpiderMan2.exe`. Keep `mods` and `licenses` beside it. Select your own USA PlayStation Rev 1 disc image when prompted. Find the suits under **SPECIAL → COSTUMES**. When upgrading, back up your saves first. Installing in a fresh folder avoids retaining older suit files.

The accompanying `.sha256` file verifies the ZIP. The archive includes a per-file manifest and checksums.
