# Spider-Noir

Original Spider-Man Unlimited Noir, with goggles, leather jacket, gloves and
boots. Standard Spider-Man donor powers, with closed fists in both hand variants.

Copy this folder into mods/suits beside either game's executable and select
Noir from the costume menu. Requires the custom modelFile suit loader.

The head/collar surface is reduced to fit the native per-part vertex limit.
Native actor: 2,789 source triangles; largest part 232 vertices. Body topology
and weights are retained. Original diffuse RGB is preserved with opaque alpha.
Recipe: docs/ports/unlimited-costume-mods.md in OpenSpideyPS1.
Source: noir/noir.fbx and SpidermanNoir_D.png, not the separate noirnew variant.
