# 2211

Spider-Man 2211 from Spider-Man Unlimited. Original helmet, outfit and compact
back attachments, using standard Spider-Man donor powers and closed fists.
The attachments keep their source arrangement and follow the torso rigidly.

Copy this folder into mods/suits beside either game's executable and select
2211 in the costume menu. Requires the custom modelFile suit loader.

The helmet and back pieces are reduced to fit native vertex limits. Main body
and limbs retain their original topology and weights. Native actor: 3,384 source
triangles; largest part 245 vertices. Original diffuse RGB is preserved with
opaque alpha. Normal and specular maps are not used by the native material.

Source: 2211/2211.fbx and Spiderman2211_D.png.
Recipe: dreamcast/tools/prepare_unlimited_2211.py and
 docs/ports/unlimited-costume-mods.md in OpenSpideyPS1.
