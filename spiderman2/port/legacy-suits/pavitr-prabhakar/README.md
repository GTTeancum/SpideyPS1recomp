# Pavitr Prabhakar

Spider-Man India from Spider-Man Unlimited, displayed as Pavitr Prabhakar.
Standard Spider-Man donor powers and animations; both native hand variants
use closed fists. All 3,524 source triangles are retained without reduction.
Largest native part: 235 vertices.

Copy this folder into mods/suits beside either game's executable and select
Pavitr Prabhakar from the costume menu. Requires the custom modelFile suit loader.
The original diffuse RGB is preserved with opaque alpha for the native material.
Normal maps are not used by the native material.

Source: india/india.fbx and SpidermanInida_D.png (original filename spelling).
Recipe: docs/ports/unlimited-costume-mods.md in OpenSpideyPS1.

Joint/ground revision: coherent knee ownership, chest kept inside the shoulder
boundary, and shoe height fitted to the native donor's sole plane. Shoes are
shortened by about 39% to normal donor proportions, with a fuller instep and
raised arch. Ankle pivots, triangle topology, and UVs are preserved.

Torso revision: default Spider-Man chest proportions, lower smooth shoulder
contours, and an inward-facing trouser lining to cover exposed cloth folds.
The approved feet and leg positions are unchanged. This is a Pavitr-only recipe.
