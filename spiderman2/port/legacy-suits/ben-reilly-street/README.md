# Ben Reilly (Street)

By DarthJak90.

Source: https://gamebanana.com/mods/448036
Author: https://gamebanana.com/members/2685073
Both spPark costume BMPs converted without pixel changes; ten other
body textures remain original SM1 Peter Parker. The separate parker NPC
texture is not installed globally. Original Dreamcast geometry and rigid
vertex assignments and source animation bank are preserved.
Standard Spider-Man powers in both games.
Install this folder in mods/suits. Requires the 19-character name update.
